# VisionPOS Edge — 極速視覺辨識庫存管理、即時產品資訊與 POS 結帳系統

支援所有手機、平板、筆電、電腦、監控與攝影機的零延遲拍照建檔、即時視覺特徵掃描辨識、即時庫存管理與購物車結帳系統。

## 核心特色

- **📸 手機/相機拍照後台建檔**：透過任何裝置鏡頭拍照（支援多角度補拍），自動萃取 **144 維緊湊複合視覺特徵指紋 (`CCVD-144`)** 並建立商品檔案。
- **🔍 開啟相機即時掃描辨識**：無需重型深度學習模型，採用 `64×64` 硬體加速取樣與零記憶體配置 (`Zero-Allocation TypedArray Arena`)，單幀辨識延遲 **< 0.45 ms**，掃描匹配立即顯示產品完整資訊、即時庫存數量與價格。
- **🌱 極致省電與硬體節能 (`Motion-Gated Eco Sleep`)**：內建 `16×16` 幀差法動態偵測，畫面靜止時自動降至 `2.5 FPS` 省電待機（節省約 94%~98% 運算能耗），商品移入鏡頭瞬間 `0 ms` 喚醒至 `20 FPS` 高速追蹤。
- **📦 即時庫存管理與 POS 購物車結帳**：支援手動/自動連續掃描入車、防超賣庫存檢核、多元付款結帳、自動扣減庫存與交易明細紀錄。
- **📹 跨平台全設備支援**：同時支援真實相機 (`WebRTC getUserMedia`)、監控/IP 攝影機串流 (`CCTV/MJPEG/HLS`)、手機原生相機拍照上傳，以及內建「互動式擬真鏡頭測試舞台」。

## 快速啟動 (本機電腦 / 伺服器)

本專案**零外部套件依賴 (Zero Dependencies)**，僅需安裝 [Node.js](https://nodejs.org/) (v18+) 即可直接啟動：

```bash
git clone https://github.com/Sinoro-Code/vision-pos.git
cd vision-pos
node server.js
```

啟動後於瀏覽器開啟 `http://localhost:3000`（同一區域網路下的手機或平板也可透過 `http://<電腦區網IP>:3000` 開啟並即時同步）。
